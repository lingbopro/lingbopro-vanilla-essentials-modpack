# lingbopro's Vanilla Essentials

This is a modpack with a bunch of essential utility mod to enhance your vanilla experience, and also with some optimizations.

The modpack is originally created for myself, but of course you can try it out ヾ(•ω•`)o

## Key Features

● Common utility mods
This modpack contains some common utility mods, such as [Tweakeroo](https://modrinth.com/mod/tweakeroo), [Xaero's Minimap](https://modrinth.com/mod/xaeros-minimap), and much more!

● Optimized for performance
THis modpack is based on [Fabulously Optimized](https://modrinth.com/modpack/fabulously-optimized), which means all the optimization mods in that modpack are available here.

## Usage

You can download the modpack from [Modrinth](https://modrinth.com/project/lingbopro-vanilla-essentials).
